# DiTz Store — Flagship Enterprise Experience

Cinematic 3D portfolio/brand experience for DiTz Store, positioned around cyber security, web engineering, application engineering, and AI/automation.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

Deploy directly to Vercel. No server state is required by this prototype.
